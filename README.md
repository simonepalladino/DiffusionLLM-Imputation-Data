# DiffusionLLM-Imputation-Data
A tabular data imputation framework comparing classical methods, deep generative models (CTGAN, TVAE), and Diffusion Reasoning LLMs (Mercury-2) on the King County House dataset. Features dynamic few-shot prompting, anti-leakage design, and achieves top downstream ML efficiency (R²=0.749 under 40% MAR missingness) using XGBoost.
